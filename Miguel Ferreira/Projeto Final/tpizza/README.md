# T-Pizza

## Descrição

Projeto desenvolvido em Vue 3 baseado no sistema T-Burguer.

O sistema foi adaptado para uma pizzaria, permitindo:

- Cadastro de pedidos
- Escolha da pizza
- Tipo de massa
- Adicionais
- Bebidas
- Alteração de status
- Exclusão de pedidos
- Alertas de validação

## Tecnologias

- Vue 3
- Vue Router
- JSON Server
- JavaScript
- HTML
- CSS

## Executar

npm install

npm run bancojson

npm run serve

## Observações

Este projeto foi desenvolvido a partir da base do sistema T-Burguer, conforme solicitado na disciplina, preservando sua arquitetura principal e adaptando-o para o segmento de pizzaria.

Os requisitos funcionais solicitados foram implementados, incluindo:

Adaptação para um novo modelo de negócio (Pizzaria);
Cadastro e gerenciamento de pedidos;
Validação de campos obrigatórios;
Alertas visuais ao usuário;
Atualização do status dos pedidos;
Exclusão de pedidos;
Navegação entre telas.

Como melhoria futura, pretende-se realizar uma atualização completa da identidade visual, substituindo todas as imagens e elementos gráficos originais por recursos exclusivos da nova marca, mantendo integralmente a lógica de funcionamento já implementada.
