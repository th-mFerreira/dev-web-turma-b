# T-Pizza

## Descrição

Projeto desenvolvido em Vue 3 baseado no sistema T-Burguer.

O sistema foi adaptado para uma pizzaria, permitindo:

- Cadastro de pedidos
- Escolha da pizza
- Tipo de massa
- Adicionais
- Bebidas
- Alteração de status
- Exclusão de pedidos
- Alertas de validação

## Tecnologias

- Vue 3
- Vue Router
- JSON Server
- JavaScript
- HTML
- CSS

## Executar

npm install

npm run bancojson

npm run serve
